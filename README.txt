SurveyApp GPS PWA版
====================

【追加機能】
・iPhone GPSの現在地取得（1回／連続）
・GPS推定精度、緯度、経度、高度の表示
・平面直角座標 X/Y への変換
・平面直角座標 I～XIX 系に対応（初期値は福井県の第VI系）
・GPS杭出し：目的点までの残距離、方向角、ΔX、ΔY
・iPhoneコンパス許可時：端末向きから右／左何度かを表示
・簡易現場マップ（現在地、目的点、保存測点）
・Appleマップで現在地を開く
・GPS測点保存とCSV出力
・従来の2点間、逆打ち、面積、単曲線、縦断、縦断曲線計算

【iPhoneでGPSを使うための条件】
1. ZIPの中身をGitHub Pages等のHTTPSサイトとして公開します。
2. iPhoneのSafariで公開URLを開きます。
3. 「GPS開始」を押し、位置情報の利用を「許可」します。
4. Safariの共有ボタン → 「ホーム画面に追加」でPWAとして利用できます。

※ file:// で直接 index.html を開いた場合、iPhoneのGPSは利用できません。
※ GPSはHTTPS（または開発用localhost）が必要です。

【福井県】
平面直角座標系は第VI系です。アプリの初期値も第VI系です。
Xは北方向が正、Yは東方向が正です。

【重要：測量精度について】
iPhone内蔵GPSは、現在地確認・概略位置・現場メモなどの用途を想定しています。
杭出し、出来形管理、境界確認など、測量精度が必要な作業の正式な測量機器の代替にはしないでください。
画面に表示される「±○m」はiPhoneが返す推定水平精度です。
GPS高度は楕円体高等として扱われる場合があり、公共測量等の標高と一致しません。

【平面直角座標変換について】
GRS80楕円体、縮尺係数0.9999のガウス・クリューゲル（横メルカトル）式で計算します。
iPhoneが返す緯度経度と国家座標は、測地成果・地殻変動・GNSS補正等の影響により高精度用途では差が生じます。
正式な成果作成では、国土地理院の座標変換・補正手順や測量機器の成果を使用してください。
